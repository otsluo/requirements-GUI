# 版本 0.0.1

## 初始版本发布

- Requirements GUI 应用程序的首次正式发布
- 提供管理 Python 包依赖的基础功能
- 设计了简洁的图形用户界面，方便查看和编辑项目依赖项
- 支持对包进行添加、删除和更新操作
- 提供导出功能，可将依赖项导出为标准的 requirements.txt 格式

## 核心包管理功能

### 包列表管理
- 添加包：支持手动输入包名、版本、操作符等信息
- 删除包：可删除选中的包条目
- 编辑包：双击包名或选中后按回车键可编辑包信息
- 刷新列表：更新包列表，显示最新的安装状态


### 包安装操作
- 安装选中：安装一个或多个选中的包
- 安装所有包：安装所有列出的包
- 更新选中：将选中的包更新到最新版本
- 卸载选中：从环境中卸载选中的包
- 列出已安装：显示当前环境中已安装的所有包

### 版本控制支持
- 支持所有标准版本操作符（==, >=, <=, >, <, !=, ~=）
- 显示包的安装状态和版本信息

## 虚拟环境管理功能
- 创建默认虚拟环境
- 选择现有虚拟环境进行包管理操作
- 环境隔离：在虚拟环境中安装的包不会影响系统Python环境

## 用户界面功能

### 主界面布局
- 系统环境信息显示区域
- 虚拟环境管理区域
- 镜像源配置区域
- requirements文件操作区域
- 预设包集合适用区域
- 包管理工具栏
- 包列表显示区域（带滚动条）
- 调试窗口（可显示/隐藏）
- 状态栏

### 菜单系统
- 文件菜单：新建、打开、保存、另存为
- 操作菜单：安装所有包、生成当前环境的requirements
- 帮助菜单：关于对话框

### 对话框
- PackageDialog：包信息输入对话框（包名、版本、操作符、来源）
- SearchPackageDialog：包搜索对话框
- LauncherDialog：启动器创建对话框
- AboutDialog：关于信息对话框

## 文件操作功能

### 基本文件操作
- 新建：创建一个新的空requirements文件
- 打开：打开现有的requirements文件（.txt格式）
- 保存：保存当前编辑的requirements文件
- 另存为：将当前文件保存到新位置

### 特殊文件功能
- 生成当前环境的requirements：自动生成当前Python环境的所有包依赖
- 拖放支持：拖入requirements.txt文件可直接导入
- 保存已安装包：将当前环境中已安装的包保存为requirements文件

## 实用工具和辅助功能

### 镜像源切换
- 支持多种国内镜像源（默认、清华、阿里、豆瓣、中科大）
- 通过下拉菜单快速切换pip包安装的镜像源
- 加速包的下载和安装过程

### 预设包集合
- AI绘画：包含torch、torchvision、diffusers、transformers等AI绘画相关包
- AI图像：包含opencv-python、Pillow、scikit-image等图像处理相关包
- AI音频：包含librosa、soundfile、pydub等音频处理相关包
- AI视频：包含moviepy、opencv-python、av等视频处理相关包
- 数据科学：包含numpy、pandas、matplotlib、scikit-learn等数据科学常用包
- Web开发：包含flask、django、fastapi、requests等Web开发常用包
- 一键加载：点击对应按钮一键加载预设包集合到当前项目

### 启动器创建
- 创建启动器：可创建带有特定虚拟环境配置的启动器文件
- 支持虚拟环境和系统Python两种方式
- 可指定Python文件路径、参数和保存位置
