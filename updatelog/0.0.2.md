# 版本 0.0.2

## 新增功能

### 包管理增强
- 新增包降级功能：支持将已安装的包降级到指定版本
- 新增包全选/取消全选功能：可快速选择或取消选择所有包
- 新增包搜索功能：可通过搜索对话框快速查找并添加包
- 新增保存已安装包功能：可将当前环境中已安装的包保存为requirements文件

### 虚拟环境管理增强
- 新增指定名称创建虚拟环境功能
- 新增创建嵌入式虚拟环境功能
- 新增自动环境检测功能

### 包列表管理增强
- 新增全选/取消全选按钮
- 新增搜索包按钮
- 新增保存已安装包按钮
- 新增预设包集合自定义功能：用户可以通过"新增预设"按钮创建自定义的预设包集合，方便快速加载常用的包组合
- 新增预设复制功能：所有预设（包括默认预设和自定义预设）都支持复制功能，用户可以右键点击预设按钮选择"复制"选项来创建新的预设

## 功能改进

### 包安装操作改进
- 安装选中包时显示更详细的进度信息
- 更新选中包时提供版本冲突检测
- 卸载选中包时增加确认对话框，防止误操作

### 用户界面改进
- 优化包列表显示，增加描述信息列
- 改进调试窗口，支持显示/隐藏切换
- 增强状态栏信息显示，提供更详细的操作状态

### 虚拟环境管理改进
- 改进虚拟环境创建流程，提供更清晰的提示信息
- 增强虚拟环境选择功能，支持显示环境路径

## Bug修复

- 修复了包版本解析时的潜在错误
- 修复了requirements文件保存时的编码问题
- 修复了虚拟环境路径包含空格时的识别问题
- 修复了部分对话框在高DPI屏幕上的显示问题

## 性能优化

- 优化包列表刷新速度，减少界面卡顿
- 改进多线程处理机制，提高包安装/更新/卸载的响应速度
- 优化内存使用，减少程序运行时的资源占用
